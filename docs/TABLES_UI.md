# Tables UI API Connection

The Tables workspace reads and writes the Tables API through the shared authenticated frontend client.

Staff can create a table with capacity and optional guest or reservation information, filter durable table records, and explicitly change table status. The global **New table** action opens this workspace so all new tables are created through the API.

Table status updates do not alter guest or reservation details in this milestone. A dedicated occupancy and reservation workflow will extend the durable model later.
