# Delivery Performance UI

The Delivery Performance workspace refreshes authenticated analytics and order data every 15 seconds. It shows active and delivered provider orders, average intake-to-delivery time, provider workload, and the active delivery queue.

Only orders with a delivery partner are included. The timer begins at order creation and ends when the delivery order first receives the delivered status. This avoids deriving delivery performance from counter, dine-in, or later status updates.
